## 📌 주요 구현

### 1. 쿼드트리 기반 지형 충돌

- 보스 전장에서 플레이어의 발밑과 낙뢰가 닿을 높이를 판정하기 위해 메쉬 기반 지면 탐색 구현. 위치를 검사할 때마다 전체 삼각형을 순회하는 부담을 줄이도록 XZ 평면 기준 쿼드트리 구성.
- 삼각형의 세 정점이 같은 사분면에 속하면 해당 자식에 배분하고, 여러 사분면에 걸치면 부모에 보관. 경계 삼각형을 여러 자식에 복제하지 않으면서 탐색 대상에 포함.
- 탐색 시 현재 노드에 보관된 면을 먼저 검사한 뒤, 검사 위치가 속한 자식으로 이동. 부모의 경계 면과 해당 경로의 하위 면을 함께 검사해 전체 맵 대신 필요한 구역만 탐색.
- 삼각형 수가 8개 이하이거나 구역의 가로 또는 세로 크기가 기준 이하이면 분할을 종료해 작은 구역까지 재귀 생성되는 것 제한.
- 같은 높이 탐색을 플레이어 이동과 낙뢰 배치에 재사용. 충돌한 면의 한 정점을 월드 좌표로 변환하고 Y값의 최댓값을 사용하므로 수평 지형 면을 전제로 처리.

### 2. 플레이어 전투 시스템

- 창, 소총, 낫의 공격 방식과 지상, 공중, 회피 상태에 따라 판정 구간을 구분. 매 갱신에서 무기 충돌체를 비활성화한 뒤 애니메이션 진행률이 해당 타격 구간에 있을 때만 활성화해 준비 동작과 타격 동작 분리.
- 소총 회피 공격은 애니메이션 안에 여러 발사 구간을 설정하고, 발사 플래그로 같은 구간에서 탄환이 반복 생성되는 것 제어. 다음 발사 전 판정 상태와 발사 플래그를 초기화해 연속 사격 구현.
- 낫 회전 공격은 충돌체 활성 구간 안에서 재타격 시점을 별도로 설정. 플래그를 전환하며 판정 상태를 초기화해 회전 동작에 맞춘 반복 타격 처리.
- 자동 조준은 적 Collider 중심과 플레이어 사이의 거리를 비교해 대상 선택. 죽은 적과 Collider가 없는 적을 제외하고, 여러 적 레이어에서도 최소 거리를 유지해 최근접 유효 대상 탐색.
- 창 돌진 공격은 조준 방향을 결정한 뒤 추가 탐색을 중단해 돌진 중 방향이 계속 바뀌지 않도록 처리. 지정한 애니메이션 구간에서만 전진하고, 동작 종료 시 방향 고정 플래그와 이동 시간 초기화.
- 소총은 발사 시점에 해당하는 애니메이션 구간에서 조준 반대 방향으로 이동하도록 구성. 누적 시간의 코사인값으로 이동량을 조절해 발사 동작에 맞춘 반동 표현.
