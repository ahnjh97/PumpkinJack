# 펌킨 잭 모작

**Pumpkin Jack** 모작 개인 프로젝트입니다.

▶️ [플레이 영상 보기](https://www.youtube.com/watch?v=UX2_LgR0Gcc)

📅 **개발 기간** : 2024.04 ~ 2024.05 (8주)  
👤 **개발 인원** : 1인

## 🛠️ 사용 기술

- C++
- DirectX 11
- HLSL
- ImGui / ImGuizmo
- FMOD

## 📌 담당 업무

### 플레이어 이동 및 전투

- 카메라 방향을 기준으로 한 이동, 점프, 회피 및 적 자동 조준 구현
- 창·소총·낫 무기 교체와 무기별 지상·공중·회피 공격 구현
- 애니메이션 진행률에 맞춘 공격 충돌 판정과 이펙트·사운드 연동

### 보스 전투 시스템

- 상태 기반 보스 패턴과 애니메이션 전환, 피격 및 사망 흐름 구현
- 칼, 기둥, 포털, 슬라임 및 데미지 영역 등 패턴별 소환 오브젝트 구현

### 쿼드트리 기반 지형 충돌

- 보스 맵의 메쉬 삼각형을 쿼드트리 노드 단위로 재귀 분할
- 플레이어가 위치한 노드의 삼각형만 검사해 불규칙한 지형의 높이 판정 최적화

### 맵 제작 도구

- ImGui와 ImGuizmo를 활용한 오브젝트 배치 및 위치·회전·크기 편집 기능 구현
- 레벨 오브젝트와 내비게이션 셀의 저장 및 불러오기 기능 구현
