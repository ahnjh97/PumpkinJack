### 플레이어 이동 및 전투

**문제**

- 카메라 방향에 맞춘 이동과 무기별 지상·공중·회피 공격을 처리하고, 공격 동작에 맞춰 충돌·이펙트·사운드를 연결해야 했습니다.
- 기존 자동 조준은 더 가까운 적을 찾은 뒤 최소 거리를 함께 갱신하지 않아, 목록 뒤쪽의 적이 대상으로 선택될 수 있었습니다.

**해결**

- 카메라 방향을 기준으로 이동·점프·회피를 처리하고, 창·소총·낫과 행동 상태에 따라 공격을 전환했습니다.
- 애니메이션 진행률에 맞춰 공격 충돌 판정과 이펙트·사운드를 실행했습니다.
- 이후 코드 개선에서 적과의 거리가 현재 최솟값보다 작을 때 대상 포인터와 최소 거리를 함께 갱신하도록 수정했습니다.
- 죽은 적과 Collider가 없는 적을 제외하고, 여러 적 레이어를 검사할 때도 같은 최소 거리를 유지했습니다.

**결과**

- 무기와 행동 상태에 맞는 전투 동작을 구성했습니다.
- 자동 조준은 검사 순서에 따른 마지막 후보 대신, 탐색 범위 안에서 거리가 가장 짧은 유효 후보를 선택하도록 수정했습니다.

### 보스 전투 시스템

**문제**

- 공격 패턴마다 소환물과 판정이 다르므로, 보스의 행동 전환과 패턴별 오브젝트를 함께 제어해야 했습니다.

**해결**

- 보스 상태에 따라 패턴·애니메이션·피격·사망 처리를 전환했습니다.
- 칼·기둥·포털·슬라임·데미지 영역을 패턴별 오브젝트로 구성해 각 공격에 연결했습니다.

**결과**

- 보스의 상태 흐름과 소환 오브젝트를 조합해 서로 다른 공격 패턴을 구성했습니다.

### 쿼드트리 기반 지형 충돌

**문제**

- 지면을 찾을 때 맵 전체 삼각형을 검사하는 범위를 줄이면서, 여러 사분면에 걸친 삼각형도 탐색에 포함해야 했습니다.
- 기존 분할 과정에는 삼각형별 임시 분류 배열과 면 배열 복사가 있었고, 탐색 과정에서는 높이 후보를 배열에 모은 뒤 최댓값을 구했습니다.

**해결**

- 메쉬 삼각형을 XZ 평면의 쿼드트리로 분류하고, 세 정점이 같은 사분면에 있으면 자식으로 내려보내고 경계를 가로지르면 부모에 남겼습니다.
- 지면 탐색은 현재 노드에 남은 삼각형을 검사한 뒤 플레이어의 XZ 위치에 해당하는 자식으로 내려가도록 구성했습니다.
- 이후 코드 개선에서 세 정점의 사분면을 직접 비교해 임시 분류 배열을 없애고, 읽기 전용 면 배열은 const 참조로 전달했습니다.
- 충돌한 면의 높이는 출력값에 즉시 누적하고, 자식 탐색에도 같은 값을 전달해 높이 후보 배열을 제거했습니다.

**결과**

- 전체 맵 대신 탐색 경로의 부모·자식 노드에 저장된 삼각형을 검사하고, 분할·탐색 중 임시 배열과 면 배열 복사를 줄였습니다.
- 높이는 충돌한 삼각형의 POINT_A를 월드 변환한 Y값 중 최댓값을 사용합니다. 수평 지형 면을 전제로 하며, 경사면의 위치별 높이 보간은 구현하지 않았습니다. 프레임 성능 개선 폭은 측정하지 않았습니다.

### 맵 제작 도구

**문제**

- 레벨 오브젝트와 내비게이션 셀을 편집하고, 배치 결과를 저장해 다시 사용할 수 있어야 했습니다.

**해결**

- ImGui와 ImGuizmo로 오브젝트 배치와 위치·회전·크기 편집 기능을 제작했습니다.
- 레벨 오브젝트와 내비게이션 셀의 저장·불러오기를 연결했습니다.

**결과**

- 툴에서 편집한 레벨 구성과 내비게이션 셀을 저장하고 다시 불러오는 제작 흐름을 마련했습니다.
